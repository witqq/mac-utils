Mac Utils — нативное приложение в строке меню macOS с анализом хранилища и переиспользуемыми сценариями автоматизации. Анализируйте папку или диск в изменяемом и полноэкранном окне с пропорциональной картой размеров, датированным кешем и переносом выбранных объектов в Корзину. Соберите шаги автоматизации мышкой, добавьте ветвление по текущему состоянию и запускайте сценарий одной глобальной клавишей. Действия управляют ролями и раскладкой дисплеев, а в Direct-сборке — закрывают уведомления и обновляют Universal Control; автозапуск при входе доступен в настройках.

## Доступность

Для Mac Utils требуется macOS 26 или новее.

- **Исходный код и задачи:** [github.com/witqq/mac-utils](https://github.com/witqq/mac-utils) — публичный репозиторий проекта.
- **GitHub Releases:** нотариально заверенный DMG и его SHA-256 доступны в [последнем релизе](https://github.com/witqq/mac-utils/releases/latest). Direct-сборка с GitHub содержит все действия, включая те, которые не может выполнять песочница Mac App Store.
- **Mac App Store:** сборка для Store с песочницей находится на проверке; ссылка на продукт появится после публикации Apple.
- **Сайт и поддержка:** [mac-utils.witqq.dev](https://mac-utils.witqq.dev) — канонический адрес продукта и поддержки.

До завершения публикации версия App Store остаётся помеченной как ожидающая. Сборку для разработки можно запустить из этого репозитория.

## Как это работает

- **Сценарии.** Сценарий — упорядоченный список действий, собранный в визуальном редакторе с типизированными полями или записанный на небольшом DSL без исполняемого кода.
- **Переключение по состоянию.** Сценарий читает текущее состояние и выполняет одну ветку при совпадении и другую — при несовпадении, поэтому одна клавиша именно переключает, а не угадывает прошлый результат.
- **Глобальные горячие клавиши.** Одна нативная клавиша macOS запускает весь сценарий, пока активно любое приложение. При конфликте или недоступной замене прежнее сочетание продолжает работать.
- **Хранилище.** Просматривайте папки и крупные файлы, выбирайте логические размеры или размеры на диске, обновляйте кешированные снимки и проверяйте выбранные объекты перед переносом в Корзину. Кнопки хранилища macOS, Загрузок и Корзины открывают системные средства управления.
- **Строка меню и окно утилит.** У Mac Utils нет значка в Dock. Из строки меню открывается общее окно с боковой навигацией: Хранилище, Сценарии, Горячие клавиши, Основные и Справка. Данные остаются локальными; интерфейс поддерживает русский, английский и язык системы.

Сценарии вызывают только зарегистрированные действия приложения. Они не могут выполнять shell-команды или произвольный загруженный код.

## Действия, доступные сейчас

| Действие | Что делает | Сборки |
| --- | --- | --- |
| Сделать основным | Делает подключённый дисплей основным дисплеем macOS. | Direct, App Store |
| Расширить дисплей | Выводит дисплей из зеркала и добавляет его как рабочее пространство. | Direct, App Store |
| Зеркалировать дисплей | Делает один дисплей зеркалом другого. | Direct, App Store |
| Режим дисплея (состояние) | Читает, является ли дисплей основным, расширенным или зеркальным, для переключения по состоянию. | Direct, App Store |
| Закрыть все уведомления | Закрывает все баннеры, алерты и стопки Центра уведомлений через «Универсальный доступ». | Direct |
| Обновить Universal Control | Перезапускает локальные службы Continuity, чтобы Universal Control соединился заново. | Direct |

Автозапуск при входе — настройка, а не действие: она использует службу объектов входа macOS и показывает фактическое состояние разрешения. Действиям только для Direct нужны возможности, которых не даёт песочница App Store; см. [Известные ограничения](docs/KNOWN_LIMITATIONS.ru.md). Новые действия подключаются к тем же реестрам; как это сделать, описано в документе [Добавление утилит, действий и источников состояния](docs/EXTENDING.ru.md).

## Быстрый старт

### Запуск сборки для разработки

Установите Xcode 26 и Command Line Tools, затем выполните:

```sh
./scripts/test.sh
./scripts/run.sh
```

В строке меню появится значок с двумя дисплеями. Откройте его, выберите **Настройки…** и пройдите встроенное знакомство.

### Первый сценарий без кода

1. Откройте **Настройки… → Сценарии** и нажмите **+**.
2. Введите название, например `Очистить экран`.
3. Нажмите **Добавить шаг** и выберите действие, например **Закрыть все уведомления** (Direct-сборка) или действие с дисплеем.
4. Добавьте другие шаги или блок **Переключение по состоянию**, если сценарий должен зависеть от текущего состояния.
5. Нажмите **Сохранить**, откройте **Горячие клавиши**, запишите сочетание и назначьте его.

Теперь клавиша запускает весь сценарий из любого приложения. Встроенная вкладка **Справка** объясняет термины и содержит готовый рецепт переключения зеркала и расширения; [руководство пользователя](docs/USER_GUIDE.ru.md) описывает каждое действие.

### Анализ хранилища

Выберите **Анализировать хранилище…** в строке меню, затем **Выбрать диск** для именованного подключённого тома, включая загрузочный диск, или **Выбрать папку…** для меньшей области. Для поддерживаемого корня тома APFS используется публичный системный каталог файлов; для папок и неподдерживаемых томов — обход каталогов с пакетным чтением метаданных, где оно доступно. Прогресс показывает этап, прошедшее время, число объектов, среднюю скорость и учтённые размеры. Процент при чтении каталога явно приблизительный; после него проверяются результаты.

Сохранённое дерево содержит проанализированные папки и файлы на всех уровнях. Раскрывайте ветви, загружайте следующие страницы и сортируйте по логическому размеру или размеру на диске без повторного анализа. Пакеты можно просматривать; очистка выбирает пакет целиком. Необязательная **Карта размеров** следует выбранной папке. Каталог предупреждает о неподтверждённой полноте защищённых областей даже без сообщённых пропусков; последнее дерево сохраняется отдельно от прежней полной резервной копии. **Обновить** заново анализирует выбранное расположение; **В Корзину** требует подтверждения и повторной проверки объектов. Успешный перенос обновляет сохранённое дерево и известные размеры, сохраняя просмотр без повторного анализа исходных файлов. **Управление** объясняет действия с данными приложения рядом с кнопками. **Доступ к диску…** показывает, как самостоятельно включить полный доступ в macOS; приложение не выдаёт его само. Кеш исторический, сумма размеров на диске не равна исключительно занятым блокам APFS, а перенос в Корзину не освобождает место сразу. Подробности навигации, доступа и очистки — в [руководстве пользователя](docs/USER_GUIDE.ru.md).

## Разработка

Swift Package Manager — источник истины для модулей. `project.yml` — источник истины для генерируемого Xcode-проекта.

```sh
./scripts/build-debug.sh
./scripts/test.sh
./scripts/check-docs.sh
./scripts/generate-xcode-project.sh
./scripts/archive-xcode-local.sh direct
./scripts/archive-xcode-local.sh app-store
```

Для генерации проекта нужен XcodeGen 2.46.0 или новее. Локальные команды архивирования используют identities из Keychain разработчика; публичная подпись и notarization выполняются через защищённые GitHub environments.

Модули:

- `MacUtilsCore` определяет действия, типизированные параметры, сценарии, источники состояния, безопасный DSL, неизменяемые снимки хранилища и чистую пропорциональную раскладку карты.
- `MacUtilsSystem` реализует системные действия, нативные клавиши и автозапуск, историю и диагностику дисплеев, анализ метаданных, общее сохраняемое дерево SQLite, доступ к папкам, ограниченный кеш и нативный перенос в Корзину и показ в Finder.
- `MacUtilsApp` собирает реестры и интерактивную модель хранилища, показывает строку меню и общее окно утилит.

Перед изменением границ модулей прочитайте документ [Архитектура](docs/ARCHITECTURE.ru.md).

## Конфиденциальность и безопасность

В Mac Utils нет аналитики, рекламы, учётных записей или сетевого клиента. Сценарии, клавиши, история дисплеев и закладки доступа к папкам остаются в локальном Application Support; снимки метаданных — в Caches, диагностика дисплеев и хранилища — в Logs. На время операции с метаданными загрузка облачных объектов запрещается для рабочего потока, затем его прежняя политика восстанавливается; содержимое файлов не открывается. Полный доступ к диску — необязательное широкое разрешение, которое вы включаете в настройках macOS. Подробности — в документе [Конфиденциальность](docs/PRIVACY.ru.md); уязвимости следует отправлять приватным способом из [SECURITY.md](SECURITY.md).
