Mac Utils — нативное приложение в строке меню для создания надёжных утилит macOS без программирования. Первая утилита управляет подключёнными дисплеями: назначает основной дисплей, расширяет рабочий стол, включает зеркало или выбирает схему в зависимости от текущего состояния.

## Доступность

Для Mac Utils требуется macOS 26 или новее.

- **Исходный код и задачи:** [github.com/witqq/mac-utils](https://github.com/witqq/mac-utils) — публичный репозиторий проекта.
- **GitHub Releases:** нотариально заверенный DMG появится вместе с v1.0.0 на странице [Releases](https://github.com/witqq/mac-utils/releases). Первого публичного релиза пока нет.
- **Mac App Store:** ссылка на продукт будет добавлена после публикации v1.0.0 компанией Apple.
- **Сайт и поддержка:** `https://mac-utils.witqq.dev` — канонический адрес, который готовится к первому релизу.

До завершения публикации DMG, версия App Store и сайт остаются помечены как ожидающие. Сборку для разработки можно запустить из этого репозитория.

## Возможности

- Работает в строке меню macOS и не показывает значок в Dock.
- Читает список дисплеев и показывает основной, расширенный или зеркальный режим.
- Собирает многошаговые сценарии мышкой через типизированные поля.
- Использует **переключение по состоянию**, чтобы выбрать ветку по текущему режиму дисплея.
- Назначает одну нативную глобальную горячую клавишу на весь сценарий.
- Безопасно изменяет клавиши: при конфликте или недоступной комбинации прежнее назначение продолжает работать.
- Хранит настройки локально и поддерживает русский, английский и системный язык.

Сценарии Mac Utils вызывают только зарегистрированные действия приложения. Они не могут выполнять shell-команды или произвольный загруженный код.

## Быстрый старт

### Запуск сборки для разработки

Установите Xcode 26 и Command Line Tools, затем выполните:

```sh
./scripts/test.sh
./scripts/run.sh
```

В строке меню появится значок с двумя дисплеями. Откройте его, выберите **Настройки…** и пройдите встроенное знакомство.

### Переключение зеркала и расширения без кода

1. Откройте **Настройки… → Сценарии** и нажмите **+**.
2. Введите название, например `Переключить рабочие дисплеи`.
3. Выберите **Добавить шаг → Переключение по состоянию → Режим дисплея**.
4. Укажите дополнительный дисплей и состояние **Зеркало**.
5. В ветку **Тогда** добавьте **Расширить дисплей** для дополнительного дисплея.
6. В ветку **Иначе** добавьте **Зеркалировать дисплей**; укажите дополнительный дисплей, а источником — основной.
7. Нажмите **Сохранить**, откройте **Горячие клавиши**, запишите сочетание и назначьте его.

Теперь одна клавиша расширяет зеркальный дисплей и снова включает зеркало, когда дисплей расширенный. Термины и последовательность действий объяснены во встроенной вкладке **Справка**.

## Разработка

Swift Package Manager — источник истины для модулей. `project.yml` — источник истины для генерируемого Xcode-проекта.

```sh
./scripts/build-debug.sh
./scripts/test.sh
./scripts/check-docs.sh
./scripts/generate-xcode-project.sh
./scripts/archive-xcode-local.sh direct
./scripts/archive-xcode-local.sh app-store
```

Для генерации проекта нужен XcodeGen 2.46.0 или новее. Локальные команды архивирования используют identities из Keychain разработчика; публичная подпись и notarization выполняются через защищённые GitHub environments.

Модули:

- `MacUtilsCore` определяет действия, типизированные параметры, сценарии, источники состояния и безопасный DSL.
- `MacUtilsSystem` реализует управление дисплеями через CoreGraphics, нативные горячие клавиши Carbon и атомарное хранение конфигурации.
- `MacUtilsApp` собирает реестры и показывает интерфейс строки меню и настроек.

Перед изменением границ модулей прочитайте документ [Архитектура](docs/ARCHITECTURE.ru.md).

## Конфиденциальность и безопасность

В Mac Utils нет аналитики, рекламы, учётных записей или сетевого клиента. Сценарии и горячие клавиши хранятся локально в контейнере Application Support. Подробности — в документе [Конфиденциальность](docs/PRIVACY.ru.md); уязвимости следует отправлять приватным способом из [SECURITY.md](SECURITY.md).
