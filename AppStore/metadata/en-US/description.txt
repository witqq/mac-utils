Mac Utils is a menu bar app that turns ready-made actions into scripts and runs each script with one global keyboard shortcut.

Build without code
Create scripts in a visual editor. Add actions, arrange them in order, and set the typed parameters each action needs. An optional data-only text editor shows the same script; it never runs shell commands or downloaded code.

React to live state
Toggle by State reads the current value every time the shortcut is pressed and chooses the matching branch. One key can extend a mirrored display and mirror it again later, following the real layout instead of remembered state.

Run from anywhere
Assign a global keyboard shortcut to any saved script. A script can contain one action or a sequence, and an existing shortcut keeps working if a replacement cannot be registered.

Ready when you sign in
Optionally launch Mac Utils at login. The General settings screen shows the live macOS approval state and links directly to Login Items when action is required.

Actions in this version
• Make a connected display the main display
• Extend a connected display
• Mirror one connected display from another
• Read a display's mode for Toggle by State

The action catalog grows with each release.

Private by design
Mac Utils has no account, analytics, advertising, or cloud service. Scripts and shortcut settings stay in the app’s local container.

Available in English and Russian. Requires macOS 26 or later.
