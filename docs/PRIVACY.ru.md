# Конфиденциальность

[English version](PRIVACY.md)

Mac Utils работает полностью на том Mac, где установлена программа.

## Сбор данных

Mac Utils не собирает, не передаёт, не продаёт и не раскрывает персональные данные. В приложении нет аналитических или рекламных SDK, учётных записей, телеметрии и сетевого клиента.

У приложения нет backend-сервиса разработчика.

## Данные на Mac

Mac Utils сохраняет только конфигурацию пользовательских автоматизаций:

- идентификаторы, названия и безопасный DSL сценариев;
- коды клавиш и модификаторы глобальных сочетаний;
- стабильные UUID CoreGraphics выбранных дисплеев;
- выбранный язык приложения в macOS user defaults.

JSON-конфигурация хранится в Application Support пользователя. В сборке Mac App Store macOS помещает её в sandbox-контейнер приложения. Файл заменяется атомарно.

Mac Utils читает текущий список и схему подключённых дисплеев для интерфейса и выполнения действий. Эта информация остаётся на Mac.

## Разрешения

Сборка Mac App Store использует App Sandbox. Нативные глобальные клавиши и изменение схемы через CoreGraphics проверены в локальной sandbox-сборке без запроса Accessibility.

Для пользовательских функций Mac Utils не запрашивает доступ к контактам, календарям, фото, камере, микрофону, геопозиции, записи экрана, всему диску или Automation.

## Диагностика

Явные developer smoke-команды могут напечатать в запустивший терминал имена и стабильные UUID дисплеев, количество объектов конфигурации и статусы. Они выполняются только при ручном запуске executable с диагностическим флагом. Эти данные никуда не отправляются.

## Удаление локальных данных

Перед удалением приложения удалите сценарии и клавиши через интерфейс. После выхода из Mac Utils оставшуюся конфигурацию можно удалить из Application Support или sandbox-контейнера средствами macOS.

Публичная справка и декларация конфиденциальности App Store должны соответствовать этому поведению. Если будущая версия добавит сеть или новую обработку данных, документ и App Store disclosure нужно обновить до релиза.

Вопросы можно отправить способом из документа [Поддержка](SUPPORT.ru.md).
