# Известные ограничения

[English version](KNOWN-LIMITATIONS.md)

- Для Mac Utils требуется macOS 26 или новее. Старые версии macOS не поддерживаются.
- Результаты хранилища — датированные снимки метаданных, в том числе при открытии из кеша. Обновление явное; вложенные изменения, перемещённые корни и устаревший выбор требуют нового анализа перед очисткой. Успешная Корзина корректирует известные сохранённые итоги и сохраняет просмотр без повторного анализа; посторонним изменениям нужно обновление. Дата и полнота остаются прежними. Корректировка известных размеров не измеряет освобождённое место. Кеш не доказывает актуальность и безопасность удаления.
- Логический размер, выделенные блоки и ёмкость тома — разные величины. Вклад жёстких ссылок учитывается один раз внутри корня; пакеты агрегируются. Клоны, общие блоки и снимки APFS не позволяют предсказать исключительно занятое или освобождаемое место по сумме блоков или переносу в Корзину. Mac Utils не очищает Корзину.
- Поддерживаемые нативные корни томов APFS используют публичный каталог файловой системы, папки и явно неподдерживаемые каталоги — обход папок. Анализ загрузочного диска включает проверенные соответствия firmlink System/Data без повторного учёта псевдонимов. Посторонние подключённые тома, цели символических ссылок и содержимое облачных папок исключаются. Каталог может не вернуть защищённые записи без сообщения ошибки: полнота такого результата всегда не подтверждена, и предупреждение видно даже при пустом списке пропусков. Полный доступ к диску не превращает результат в доказательство полноты.
- На время каждой синхронной операции анализа с метаданными загрузка облачных объектов запрещается, затем прежняя политика рабочего потока восстанавливается. Если защиту включить нельзя, анализ завершается ошибкой. Каталог использует нативный признак облачного объекта и заблокированный ввод-вывод вместо запросов старого статуса загрузки iCloud. Изменение поколения, небезопасные пути папок и неизвестные несовпадения итоговых идентичностей останавливают анализ; только явное отсутствие поддержки каталога разрешает обход папок. Подтверждённая замена объекта каталога по тому же имени у проверенного родителя сохраняет первую историческую строку и размеры один раз, исключает новый вклад и отмечает объект/родителей неполными с замечанием. Это узкое исключение не превращает результат в текущую картину файловой системы: корень/родители проверяются строго, очистка отклоняет изменённую идентичность. Изменения папок, противоречивые метаданные прежней идентичности и неизвестные ошибки доказательств/SQL по-прежнему останавливают анализ. Время зависит от содержимого диска, доступа и файловой системы; фиксированный срок не гарантируется.
- Успешно опубликованное дерево схемы 3 сохраняет проанализированную иерархию; краткий JSON и список крупнейших объектов ограничены отдельно. Ветви UI загружают по 200 детей через «Показать ещё»; сортировка соседних объектов и фокус карты читают индекс без анализа файлов. Карта показывает до 255 ненулевых детей и недоступную для выбора сумму остальных; список крупных объектов — до 200 файлов/целых пакетов. Эти пределы не удаляют детей из индекса. Сохраняются до 1 000 подробностей замечаний, остальные считаются. Кеши контекстов, точные идентичности жёстких ссылок и раскрытые страницы UI занимают память; она не постоянна.
- Прогресс показывает этап, прошедшее время, число объектов, среднюю скорость и учтённые размеры. Если том сообщает число объектов, процент каталога приблизительный и остаётся ниже 100% до конца чтения; затем ещё проверяется результат. У обычного обхода папки нет достоверного общего числа для процента.
- Навигация по папкам/пакетам использует одно сохранённое дерево и дату. Содержимое пакетов можно просматривать, но нельзя переносить в Корзину отдельно. Обновление анализирует выбранный сохранённый корень, а не ветвь фокуса. Полные деревья схемы 1 читаются; компактному обзору схемы 2 нужен один явный запуск обновления. Finder показывает первый выбранный объект; подтверждённая Корзина обрабатывает несколько. Карта изначально скрыта, размеры областей меняются стандартным разделителем.
- Краткий JSON хранит до двенадцати корней в пределах 32 МиБ отдельно от приватных поколений SQLite с мягким бюджетом 8 ГиБ и резервом свободного места 512 МиБ при построении. Удаляются целые неактивные поколения; активные/последний индекс имеют приоритет, читатели откладывают удаление до освобождения. Завершённое полное дерево становится последним результатом и при неподтверждённой полноте; прежний полный результат сохраняется отдельно. Старый неполный компактный результат сохраняет прежний полный кеш. Слишком большой краткий снимок может показываться без сохранения. «Управление» объясняет удаление метаданных: очистка сохраняет закладки, сброс забывает их. Исходные файлы и разрешения macOS не меняются.
- Очистка сначала проверяет принадлежность объекта сохранённому дереву, затем текущую идентичность и границы. Отклоняются внутренние объекты пакетов, корни анализа, защищённые системные деревья, дома аккаунта/контейнера и их родители, собственный кеш дерева и его родители. Весь кеш дерева исключён из анализа с замечанием; анализ самого кеша отклоняется. Редакции дерева требуют нативного copy-on-write клонирования приватной файловой системы кеша; первое изменение старого формата 1 может создавать индексы метаданных. Ошибка изменения индекса после переноса сохраняет исторический просмотр с отключённой Корзиной до обновления. Ошибка записи снимка сохраняет точную редакцию сессии с предупреждением; она может не пережить перезапуск. Прежний результат после перезапуска доступен только для просмотра до явного обновления. Защита сохраняется до переноса; ошибка её записи отклоняет очистку. Пересекающиеся результаты сбрасываются, устаревшие поколения нельзя снова изменять. Эти ошибки не отменяют перенос. Корзина принимает путь: одновременную замену после последней проверки исключить нельзя. Перемещённый корень сохраняет ID доступа, но очистка по историческому пути отклоняется до обновления.
- Доступ к выбранным папкам и entitlements закладок компилируются в обеих release-конфигурациях, но работа такого доступа в подписанной Store-сборке локально ещё не проверена. «Доступ к диску» объясняет необязательный полный доступ и открывает настройки конфиденциальности; включаете разрешение вы. Оно может сократить запросы к защищённым папкам, но не заменяет выбор папки в Store и не снимает все системные ограничения. Приложение не проверяет разрешение чтением личных файлов. Если переход не сработал, используйте показанный ручной маршрут настроек.
- Неактивный зеркальный дисплей иногда отдаёт только общее аппаратное имя, пока его снова не расширят. Mac Utils продолжает определять его по стабильному UUID CoreGraphics.
- Независимые режимы и взаимное расположение восстанавливаются только из достоверной истории для того же стабильного UUID дисплея. Геометрии также нужно запомненное положение текущего основного дисплея как общая точка отсчёта. При отсутствующей или частичной истории дисплеи с невосстановимой геометрией получают детерминированное запланированное положение, даже если сохранённые режимы доступны; вновь независимый дисплей по умолчанию размещается справа. Запуск с уже зеркальной группой не позволяет восстановить ненаблюдавшуюся раскладку. Недоступный сохранённый режим заменяется режимом по умолчанию либо собственным режимом панели, совместимым с текущим поворотом. Если каталог не предлагает ни одного, остаётся текущий режим. macOS может нормализовать неподдерживаемые зазоры и перекрытия.
- Mac Utils читает поворот, но не меняет его через приватные API. Несовпадение сохранённого и фактического поворота отклоняет восстановление сохранённого режима и требует настроек дисплеев macOS. Восстановление режимов и расположения обоих участников проверяется моделируемым драйвером и физическим циклом обоих направлений зеркала на Odyssey G61SD (основной, 2560×1440 при 120 Гц, поворот 0°, начало 0,0) и G27Q (расширенный справа, 1440×2560 при 72 Гц, поворот 270°, начало 2560,0). Итоговое нативное состояние совпало с исходными ролями, координатами, логическими/пиксельными режимами, частотами и поворотом; пользователь подтвердил изображение без обрезания и положение справа. Это свидетельство относится к наблюдаемой паре и раскладке; другое оборудование и конфигурации требуют проверки.
- Mac Utils не сохраняет и не восстанавливает положение окон других приложений. macOS может переставить окна при любой смене ролей или раскладки дисплеев.
- macOS или другое приложение может занять глобальное сочетание. Mac Utils показывает ошибку и сохраняет прежнее назначение, если замену применить нельзя.
- macOS может потребовать подтверждения автозапуска в Системных настройках. Mac Utils не обходит это системное решение.
- **Обновить Universal Control** доступно только в Direct-сборках и исключено из сборки Mac App Store. Действие перезапускает локальные процессы Continuity, может ненадолго прервать связанные службы Apple и не гарантирует соединение, если не выполнены базовые требования Universal Control. Оно не сопрягает и не передаёт Magic Trackpad. См. [отчёт о реализуемости](MAGIC_TRACKPAD_FEASIBILITY.ru.md).
- **Закрыть все уведомления** доступно только в Direct-сборках и исключено из сборки Mac App Store. Действию нужно право «Универсальный доступ»; оно опирается на структуру Центра уведомлений в Accessibility (четыре subrole уведомлений, включая два вида стопок) и на локализованные имена его действий «Закрыть» и «Очистить все» (читаются из системного bundle), поэтому после обновления macOS, меняющего эту структуру, может потребоваться обновление. Уведомления, пришедшие во время работы действия, не догоняются. Сбой сценария, запущенного по глобальной клавише, приложение не показывает; отсутствие права видно только по системному запросу macOS.
- Для подписанной сборки нужны Apple Developer identities и профиль Keychain `mac-utils-notary`, описанные в [инструкции по подписи и notarization](SIGNING.ru.md). Эти данные хранятся локально или управляются Apple Cloud и намеренно не попадают в репозиторий.
