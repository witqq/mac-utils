# Анализ переключения Magic Trackpad

[English version](MAGIC_TRACKPAD_FEASIBILITY.md)

## Цель пользователя

Один Magic Trackpad используется с двумя Mac. После нажатия глобальной горячей клавиши Mac Utils на активном Mac трекпад должен начать работать с ним; повторная передача должна возвращать устройство обратно.

## Вывод

Точный сценарий с одной клавишей технически можно исследовать как будущую функцию, но один Mac не может надёжно выполнить его как локальную Bluetooth-команду. Поддерживаемая архитектура требует Mac Utils на обоих компьютерах и доверенного протокола передачи:

1. принимающий Mac просит второй Mac освободить выбранный трекпад;
2. второй Mac закрывает Bluetooth-соединение и подтверждает результат;
3. принимающий Mac открывает собственное соединение с уже сопряжённым трекпадом;
4. интерфейс явно сообщает о частичной ошибке, а не показывает ложный успех.

Публичный API Apple `IOBluetoothDevice` позволяет перечислить сопряжённые устройства и запросить создание или закрытие базового соединения. Поэтому отдельный прототип возможен без приватных frameworks. Однако API не создаёт атомарную передачу владения между двумя Mac: локальный процесс не может заставить другой компьютер освободить HID-устройство. Нужны координация между компьютерами и восстановление после ошибок.

## Ограничения распространения и конфиденциальности

- Для Mac App Store потребуются Bluetooth entitlement песочницы и понятное объяснение использования Bluetooth. Entitlement даёт приложению возможность запросить доступ, но macOS всё равно может потребовать явное разрешение пользователя.
- Автоматическое обнаружение второго Mac или передача команд по сети добавят локальное сетевое взаимодействие в продукт, где сейчас нет сетевого клиента. Функция должна быть добровольной, с аутентифицированным связыванием двух установок Mac Utils, обновлёнными правилами конфиденциальности и отдельной проверкой сетевых entitlements App Store.
- Трекпад должен быть заранее сопряжён с обоими Mac. Apple документирует сопряжение через кабель и ручное подключение или отключение; Mac Utils не должна скрыто забывать или заново сопрягать устройство.
- Горячая клавиша не должна оставлять оба приложения в состоянии, где каждое считает трекпад своим. Протоколу нужны таймауты, подтверждение, безопасный повтор и видимый ручной путь восстановления.

## Рекомендуемый следующий шаг

Не добавлять Bluetooth-код в текущий релиз. Сначала передать на оба физических Mac отдельный Direct DMG, подписанный Developer ID и прошедший notarization, и проверить его с одним Magic Trackpad. Прототип должен использовать только публичные вызовы `IOBluetooth`, сохранять точные коды `IOReturn`, подтвердить сопряжение конкретного трекпада с обоими Mac и проверить ситуации, когда один Mac спит, выключен или отклоняет соединение. Работу над TestFlight и App Store следует начинать только после воспроизводимого аппаратного теста.

Для использования прямо сейчас безопаснее штатный Universal Control: трекпад остаётся подключённым к одному Mac, а указатель и клавиатура управляют соседними Mac. Universal Control умеет автоматически восстанавливать связь, но Apple предоставляет управление через Пункт управления и настройки дисплеев, а не через API приложения для собственной горячей клавиши Mac Utils.

## Первичные источники

- [IOBluetoothDevice](https://developer.apple.com/documentation/iobluetooth/iobluetoothdevice) описывает список сопряжённых устройств, состояние соединения, `openConnection()` и `closeConnection()`.
- [Bluetooth entitlement App Sandbox](https://developer.apple.com/documentation/bundleresources/entitlements/com.apple.security.device.bluetooth) описывает право, необходимое sandbox-приложению для работы с Bluetooth-устройствами.
- [Настройка App Sandbox для macOS](https://developer.apple.com/documentation/xcode/configuring-the-macos-app-sandbox) поясняет, что hardware entitlement сообщает о намерении приложения, но не заменяет разрешение пользователя.
- [Настройка Magic Trackpad с Mac](https://support.apple.com/en-asia/119917) описывает сопряжение через кабель и обычное беспроводное использование.
- [Universal Control](https://support.apple.com/en-us/102459) описывает совместное использование клавиатуры, мыши или трекпада с соседними Mac и штатные способы управления соединением.
