# Анализ совместного использования Magic Trackpad

[English version](MAGIC_TRACKPAD_FEASIBILITY.md)

## Цель пользователя

Один Magic Trackpad используется с двумя соседними Mac без ручного сопряжения и переподключения при каждом переключении.

## Вывод

Magic Trackpad следует оставить подключённым к одному Mac, а вторым Mac управлять через штатную функцию Apple Universal Control. В таком режиме владельцем трекпада остаётся основной Mac, а macOS передаёт ввод указателя и клавиатуры между соседними компьютерами.

Mac Utils не сопрягает, не отключает и не передаёт трекпад. Публичные Bluetooth API Apple не предоставляют надёжной межкомпьютерной передачи HID-устройства. Во время проверки принимающий Mac мог кратковременно показать Bluetooth-подключение, после чего устройство возвращалось к исходному Mac и не передавало ввод.

Вместо этого Direct-сборка предоставляет действие **Обновить Universal Control**. Оно локально перезапускает фиксированный набор процессов Continuity, после чего macOS может заново установить Universal Control. Действие использует общий движок сценариев, поэтому его можно добавить мышкой и назначить на глобальную горячую клавишу. Обнаружения второго Mac по сети, доверенного связывания и хранения данных трекпада нет.

## Ограничения распространения и конфиденциальности

- **Обновить Universal Control** доступно только в Direct-сборке: действие завершает системные процессы и полагается на их повторный запуск через launchd. Из сборки Mac App Store оно исключено при компиляции.
- Обновление может ненадолго прервать Universal Control, Handoff, AirDrop, Sidecar или Universal Clipboard на этом Mac.
- Действие помогает восстановлению, но не является официальным API соединения Apple. Оно не гарантирует результат, если не выполнены требования Universal Control, различаются настройки Apple Account, мешает сеть или отключены системные параметры.
- Запускайте действие на Mac, соединение которого нужно восстановить. При необходимости назначьте отдельную локальную горячую клавишу на каждом Mac и выполните обновление на обоих.

## Рекомендуемый следующий шаг

Создайте сценарий из одного действия и назначьте горячую клавишу по [руководству пользователя](USER_GUIDE.ru.md). Оставьте трекпад сопряжённым с его основным Mac и включите Universal Control средствами macOS на обоих компьютерах.

## Первичные источники

- [Настройка Magic Trackpad с Mac](https://support.apple.com/en-asia/119917) описывает сопряжение через кабель и обычное беспроводное использование.
- [Universal Control](https://support.apple.com/en-us/102459) описывает совместное использование клавиатуры, мыши или трекпада с соседними Mac и штатные способы управления соединением.
