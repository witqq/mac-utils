# Руководство пользователя Mac Utils

[English version](USER_GUIDE.md)

Mac Utils работает из строки меню macOS. Программа сохраняет последовательность зарегистрированных действий как сценарий и позволяет запускать весь сценарий одной глобальной горячей клавишей из любого приложения.

## Требования и установка

Для Mac Utils требуется macOS 26 или новее.

Первая публичная сборка пока не опубликована. После выхода v1.0.0 будут доступны два канала:

- нотариально заверенный DMG из GitHub Releases по адресу `https://github.com/witqq/mac-utils/releases`: откройте образ и перетащите **Mac Utils** в **Applications**;
- версия Mac App Store по ссылке, которая появится после публикации Apple.

До публикации разработчики могут выполнить `./scripts/run.sh` в локальной копии исходного кода.

## Первый запуск

У Mac Utils нет значка в Dock. Найдите в строке меню значок с двумя дисплеями.

1. Откройте меню Mac Utils.
2. Выберите **Настройки…**.
3. Прочитайте карточки знакомства или откройте вкладку **Справка**.
4. Выберите **Язык → Системный**, **English** или **Русский**. При системном режиме используется язык macOS.

## Термины дисплеев

- **Основной дисплей** содержит строку меню и задаёт начало координат рабочего стола.
- **Расширенный дисплей** добавляет отдельное пространство рабочего стола.
- **Зеркало** показывает содержимое другого дисплея.
- **Переключение по состоянию** читает текущее значение. При совпадении выполняется ветка **Тогда**, при несовпадении — **Иначе**.

Окно в строке меню показывает подключённые дисплеи, их режим и разрешение. Кнопки **Основной**, **Расширить** и **Зеркалировать** вызывают те же зарегистрированные действия, что и сценарии.

## Сборка сценария мышкой

1. Откройте **Настройки… → Сценарии**.
2. Нажмите **+** и введите понятное название.
3. Нажмите **Добавить шаг** и выберите действие или источник для **переключения по состоянию**.
4. Выберите дисплеи по именам macOS. В конфигурации Mac Utils сохраняет стабильные идентификаторы CoreGraphics.
5. Меняйте порядок стрелками или перетаскиванием. Шаг можно дублировать или удалить.
6. Нажмите **Проверить**, чтобы проверить все действия, параметры и вложенные ветки.
7. Нажмите **Сохранить**.

Удаление сценария требует подтверждения и удаляет связанные назначения клавиш. Удаление шага из черновика подтверждается отдельно.

## Рецепт переключения зеркала и расширения

Создайте один шаг **Переключение по состоянию → Режим дисплея**:

- **Дисплей:** дополнительный дисплей.
- **Если состояние:** **Зеркало**.
- **Тогда:** **Расширить дисплей** для того же дополнительного дисплея.
- **Иначе:** **Зеркалировать дисплей**, где дополнительный дисплей выбран как **Дисплей**, а основной — как **Источник**.

Это универсальное переключение по состоянию: при каждом нажатии читается реальный режим дисплея, а не запоминается предыдущая ветка.

## Назначение и изменение горячей клавиши

1. Откройте **Настройки… → Горячие клавиши**.
2. Выберите сохранённый сценарий.
3. Нажмите **Записать сочетание** и клавишу вместе с Control, Option или Command. Escape отменяет запись.
4. Нажмите **Назначить**.

Одна клавиша выполняет все шаги сценария по порядку. Для замены нажмите **Изменить**, запишите новое сочетание и нажмите **Сохранить изменение**. Mac Utils сначала регистрирует замену и только потом снимает прежнее назначение. Если macOS или другое назначение приложения отклоняет замену, прежняя клавиша продолжает работать.

Удаление горячей клавиши требует подтверждения, но не удаляет сценарий.

## Дополнительный редактор DSL

Рекомендуется визуальный конструктор. Режим **Текст DSL** показывает то же безопасное представление сценария для опытных пользователей. Он не вычисляет выражения, не читает файлы, не запускает процессы и shell-команды.

Одно действие занимает одну строку, параметры именованные и заключены в кавычки:

```text
extend-display display="SECONDARY-DISPLAY-UUID"
```

Переключение по состоянию записывается явными блоками:

```text
@toggle provider="display.mode" equals="mirror" display="SECONDARY-DISPLAY-UUID"
  @match
    extend-display display="SECONDARY-DISPLAY-UUID"
  @otherwise
    mirror-display display="SECONDARY-DISPLAY-UUID" source="MAIN-DISPLAY-UUID"
@end
```

Комментарии начинаются с `#`. Возврат к визуальному конструктору возможен только после успешного разбора и проверки всего текста, поэтому ошибка не заменит последнюю корректную визуальную модель.

## Локальные данные и восстановление

Конфигурация хранится в JSON внутри Application Support приложения. Версия Mac App Store автоматически получает стандартный sandbox-контейнер. Запись выполняется атомарно.

Не изменяйте файл при запущенном Mac Utils. При ошибке JSON или схемы программа запускается с безопасной пустой конфигурацией и показывает причину. Сохранённый сценарий или клавиша, которые сейчас нельзя активировать, остаются видимыми: их можно исправить или удалить без скрытой потери данных.

## Решение проблем

- **Дисплей отсутствует:** подключите его и нажмите обновление в окне строки меню.
- **У зеркального дисплея общее аппаратное имя:** один раз расширьте его, чтобы macOS снова отдала локализованное имя. Стабильный идентификатор не меняется.
- **Сочетание недоступно:** запишите другое. При неудачной замене прежняя клавиша остаётся активной.
- **Сценарий не проходит проверку:** прочитайте локализованное сообщение со строкой и столбцом; после исправления можно вернуться в конструктор.
- **Программы нет в Dock:** это ожидаемо, Mac Utils работает как приложение строки меню.
