# Mac Utils v1.1.0

[Русская версия](v1.1.0.ru.md)

## Highlights

- Choose **Settings → General → Launch Mac Utils at login** to start the menu bar app automatically after signing in.
- See the actual status reported by macOS, including cases that require approval in System Settings.
- Open **Login Items & Extensions** directly from Mac Utils and refresh the status after changing system approval.

Mac Utils uses the public `SMAppService.mainApp` API. It never enables automatic launch during startup and does not install a custom LaunchAgent or background helper.

## Compatibility and data

Mac Utils v1.1.0 requires macOS 26 or later. Existing scripts, visual workflows, and shortcut assignments continue to use configuration schema 1; no data migration is required.

The application still has no analytics, advertising, account system, or network client. Launch-at-login registration is managed by macOS and changes only after an explicit user action.
