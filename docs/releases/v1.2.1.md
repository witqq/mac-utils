# Mac Utils v1.2.1

[Русская версия](v1.2.1.ru.md)

## Highlights

- The menu bar popover opens attached under its status item. It previously appeared as a panel detached from the menu bar, in a position unrelated to the icon.
- The popover takes keyboard focus, so Escape closes it. Selecting the status item again or clicking outside the popover also closes it.
- Its Quit control reads **Quit Mac Utils** again instead of showing an unsubstituted format specifier.

`NSPopover` places itself next to the status item using its content size, and the popover content reported no size of its own. Publishing that size restores both the anchoring and the keyboard focus that closing depends on.

## Compatibility and data

Mac Utils v1.2.1 requires macOS 26 or later. Scripts, visual workflows and shortcut assignments are unchanged and continue to use configuration schema 1.
