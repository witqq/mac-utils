# Mac Utils v1.0.0

[English version](v1.0.0.md)

Статус: **release candidate — пока не опубликован**.

Mac Utils v1.0.0 — первый release candidate нативного конструктора утилит в строке меню для macOS 26+.

## Главное

- Сборка сценариев дисплеев мышкой без знания DSL.
- Назначение основного дисплея, расширение рабочего стола и зеркало выбранного источника.
- Живое **переключение по состоянию** между зеркалом и расширением одной клавишей.
- Одна нативная глобальная горячая клавиша на многошаговый сценарий.
- Безопасное изменение клавиши: при конфликте прежнее назначение остаётся активным.
- Полный интерфейс и справка на русском и английском.
- Сценарии и настройки клавиш остаются локально на Mac.

## Пример

Создайте **Переключение по состоянию → Режим дисплея**, сравните дополнительный дисплей с состоянием **Зеркало**, добавьте **Расширить дисплей** в ветку **Тогда**, а **Зеркалировать дисплей** — в ветку **Иначе**. Назначьте одну клавишу на весь сценарий.

## Требования

- macOS 26 или новее.
- Не менее двух подключённых дисплеев для переключения зеркала и расширения.

## Распространение

Финальный релиз будет содержать:

- подписанный и нотариально заверенный `Mac-Utils-v1.0.0.dmg` с SHA-256 по адресу `https://github.com/witqq/mac-utils/releases`;
- версию Mac App Store после одобрения Apple;
- поддержку и документацию по адресу `https://mac-utils.witqq.dev`.

До завершения соответствующих задач этих загрузок нет. Не распространяйте локальные unsigned-архивы как v1.0.0.

## Конфиденциальность

В Mac Utils нет аналитики, рекламы, учётных записей, сетевого клиента или backend. Схема дисплеев, сценарии и горячие клавиши остаются локально. Подробности — в документе [Конфиденциальность](../PRIVACY.ru.md).

## Проверки release candidate

- SwiftPM и Xcode проходят 61 тест с превращением предупреждений в ошибки.
- Direct- и App Store-сборки и архивы содержат `x86_64` и `arm64`.
- Runtime smoke App Sandbox проходит для конфигурации, UI, чтения/изменения дисплеев и физической глобальной клавиши.
- На тестовом оборудовании выполнены обе ветки mirror/extend toggle, после чего восстановлена наблюдаемая исходная схема.

Ограничения перечислены в документе [Известные ограничения](../KNOWN_LIMITATIONS.ru.md).
