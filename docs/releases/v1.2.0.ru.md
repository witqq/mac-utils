# Mac Utils v1.2.0

[English version](v1.2.0.md)

## Главное

- **Закрыть все уведомления** (Direct-сборка): одно действие закрывает все баннеры, алерты и стопки Центра уведомлений, включая алерты, которые висят на экране до ручного закрытия. Оно использует собственные локализованные действия Центра уведомлений «Закрыть» и «Очистить все» и требует права «Универсальный доступ»; macOS запрашивает его при первом запуске.
- **Обновить Universal Control** (Direct-сборка): перезапускает локальные службы Continuity, чтобы Universal Control снова соединил трекпад и курсор между Mac.
- **Запуск при входе**: включите **Настройки → Основные → Запускать Mac Utils при входе**, проверяйте фактическое состояние разрешения macOS и открывайте «Объекты входа» прямо из приложения.
- **Повёрнутые дисплеи сохраняют режим**: дисплей, выходящий из зеркалирования, возвращается к собственному режиму по умолчанию, а не остаётся в режиме зеркальной пары, поэтому вертикальный монитор больше не рисуется с горизонтальным соотношением сторон после смены раскладки.

Mac Utils теперь представлен как конструктор сценариев: собирайте готовые действия в сценарии и запускайте каждый сценарий одной глобальной горячей клавишей. Набор действий растёт с каждым выпуском.

## Direct-сборка и сборка Mac App Store

Нотариально заверенный DMG с GitHub — полная Direct-сборка. Сборка для Mac App Store в песочнице содержит действия для дисплеев, переключение по состоянию, горячие клавиши и автозапуск; песочница App Store не позволяет управлять другими приложениями через «Универсальный доступ» и перезапускать системные процессы, поэтому два действия только для Direct из неё исключены.

## Совместимость и данные

Для Mac Utils v1.2.0 требуется macOS 26 или новее. Существующие сценарии, визуальные схемы и назначения горячих клавиш продолжают использовать схему конфигурации 1; миграция данных не требуется.

В приложении по-прежнему нет аналитики, рекламы, учётных записей или сетевого клиента. Право «Универсальный доступ» запрашивается только при запуске действия с уведомлениями и никогда не используется для чтения их содержимого.
