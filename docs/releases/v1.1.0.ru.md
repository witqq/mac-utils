# Mac Utils v1.1.0

[English version](v1.1.0.md)

## Главное

- Включите **Настройки → Основные → Запускать Mac Utils при входе**, чтобы приложение автоматически появлялось в строке меню после входа в учётную запись.
- Проверяйте фактическое состояние macOS, включая необходимость разрешения в Системных настройках.
- Открывайте раздел **Объекты входа и расширения** прямо из Mac Utils и обновляйте состояние после изменения системного разрешения.

Mac Utils использует публичный API `SMAppService.mainApp`. Приложение никогда не включает автозапуск во время старта и не устанавливает собственный LaunchAgent или фоновый helper.

## Совместимость и данные

Для Mac Utils v1.1.0 требуется macOS 26 или новее. Существующие сценарии, визуальные схемы и назначения горячих клавиш продолжают использовать схему конфигурации 1; миграция данных не требуется.

В приложении по-прежнему нет аналитики, рекламы, учётных записей или сетевого клиента. Регистрацией автозапуска управляет macOS, а её изменение происходит только после явного действия пользователя.
