# Mac Utils v1.3.0

[Русская версия](v1.3.0.ru.md)

## Storage analysis

Choose a disk or folder and explore a saved hierarchy sorted by logical or allocated size. Expand folders and packages, load additional pages, focus a branch, or reopen saved results without rescanning. The largest-items list and optional size map help locate large objects. Refresh explicitly measures the selected root again.

Supported APFS volume roots use the public filesystem catalog; ordinary folders and explicitly unsupported catalogs use metadata traversal. Progress shows phases, elapsed time and processed objects, with an approximate percentage when a catalog object-count estimate is available. Catalog results warn that protected-area coverage is unverified. Allocated sums are approximate accounting and do not establish exclusive or reclaimable space on APFS.

If catalog validation confirms that a different file replaced an accepted file at the same verified path during analysis, the first historical row and size remain counted once; the newer contribution is omitted and coverage is marked incomplete. Refresh is required for current sizes, and cleanup refuses the replaced identity. Root, parent, directory and same-identity contradictions still stop analysis.

Move selected files or whole folders to the system Trash after reviewing their paths. A folder moves with all its contents and remains recoverable until Trash is emptied in Finder. Successful moves update the saved tree without rescanning, preserving expanded branches, loaded pages and browsing choices. Cache failures are reported; historical results are protected from further Trash until explicit Refresh. The app does not run automatic cleanup or permanently delete files.

Buttons and management actions include explanations. Native shortcuts open macOS Storage settings, Downloads and Trash. Optional Full Disk Access remains a user decision in System Settings; the app cannot grant it. Store builds also need a native disk/folder selection grant, and signed live Store storage access remains unverified locally.

## Display restoration

Mirror/extend switching restores remembered supported independent modes and relative display positions by stable UUID. Choosing a different main display preserves pairwise offsets rather than moving a portrait display to a fixed side. Without reliable geometry history, fallback placement remains deterministic. Rotation is observed rather than changed by the app; a rotation mismatch requires correction in macOS Displays settings.

Both mirror directions were checked on an Odyssey G61SD main display and portrait G27Q to its right, and the user confirmed the complete portrait image and restored placement. Other hardware and arrangements require their own verification.

## Utility window and compatibility

Storage, scripts, shortcuts, general settings and help share a sidebar and a resizable window with native full-screen mode. Mac Utils continues running from the menu bar when the window closes.

Requires macOS 26 or later. Existing scripts and shortcut assignments retain configuration schema 1. Display history, storage bookmarks, analysis caches and bounded diagnostics are stored separately and locally. Nothing is uploaded automatically. The Direct distribution is available through GitHub; the Mac App Store build remains pending Apple publication.
