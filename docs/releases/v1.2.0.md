# Mac Utils v1.2.0

[Русская версия](v1.2.0.ru.md)

## Highlights

- **Dismiss all notifications** (Direct build): one action closes every Notification Center banner, alert, and stacked group, including alerts that stay on screen until they are closed by hand. It uses the Notification Center's own localized Close and Clear All actions and needs Accessibility access; macOS asks for it on the first run.
- **Refresh Universal Control** (Direct build): restarts the local Continuity services so Universal Control can reconnect the trackpad and cursor between Macs.
- **Launch at login**: turn on **Settings → General → Launch Mac Utils at login**, see the actual approval state reported by macOS, and open Login Items directly from the app.
- **Rotated displays keep their mode**: a display that leaves mirroring returns to its own default mode instead of keeping the mode macOS chose for the mirror pair, so a portrait display no longer renders with a landscape aspect ratio after a layout change.

Mac Utils is now presented as a script builder: compose ready-made actions into scripts and run each script with one global keyboard shortcut. The action catalog grows with each release.

## Direct build and Mac App Store build

The notarized DMG from GitHub is the full Direct build. The sandboxed Mac App Store build contains the display actions, Toggle by State, shortcuts, and launch at login; the App Store sandbox cannot control other applications through Accessibility or restart system processes, so the two Direct-only actions are compiled out of it.

## Compatibility and data

Mac Utils v1.2.0 requires macOS 26 or later. Existing scripts, visual workflows, and shortcut assignments continue to use configuration schema 1; no data migration is required.

The application still has no analytics, advertising, account system, or network client. Accessibility access is requested only when the notification action runs and is never used to read notification content.
